# Ashley | Portfolio

Bilingual (French / English) portfolio of Ashley, computer science student: machine learning, web, mobile and embedded projects, built end to end and running online.

**Live site:** <https://ornella-bit.github.io/My-portfolio-web-site/>

## Projects shown on the site

- **Predictive maintenance** – remaining useful life of engines (NASA data), Gradient Boosting, Streamlit demo
- **Mini-GMAO** – maintenance tracking web app (Flask, SQLite)
- **Mini-GMAO Mobile** – Android field app (Flutter, Dart, REST API)
- **Tank supervisor** – sensors, alarms and charts, Python then ESP32
- **Baobab Sève** – data-quality checks, production graph, AI copilot (hackathon project)
- **Tekmoryx** – anomaly detection in public spending (in progress)

## About this site

Plain HTML, CSS and JavaScript. No framework, no build step, no dependencies.

| File | Role |
| --- | --- |
| `index.html` | Content (English) and the view-only CV window |
| `style.css` | Design tokens, layout, animations |
| `script.js` | Language switch, animated line, scroll effects, project rows |
| `lang.js` | French texts, matched to the English texts in `index.html` |
| `og.png` | Preview image shown when the link is shared |

Features: FR/EN switch, animated background, accessible unfolding project rows, respect for "reduce motion", responsive layout.

## Run it locally

Open the folder in VS Code, install the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**.
